## Cara Menjalankan Server (Getting Started)

Ikuti langkah-langkah berikut untuk menjalankan aplikasi di komputer lokal Anda:

1. **Navigasi ke folder proyek**:
   Buka terminal dan masuk ke folder `duitku`:
   ```bash
   cd duitku
   ```

2. **Instalasi Dependensi** (jika pertama kali):
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan**:
   ```bash
   npm run dev
   ```

4. **Buka Browser**:
   Buka [http://localhost:3000](http://localhost:3000) untuk melihat hasilnya.

> **Catatan**: Jika muncul error `npm: command not found`, pastikan konfigurasi NVM sudah benar di file `.zshrc` atau terminal Anda.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
